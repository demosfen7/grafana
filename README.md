# Weather App — OpenWeather CLI

Консольное приложение для получения текущей погоды через [OpenWeather API](https://openweathermap.org/).

## Возможности

- Поиск погоды по **названию города** или **координатам**
- Красивое цветное меню (colorama)
- **Кэширование** последнего успешного запроса (`weather_cache.json`)
- **Автоматические повторы** при сбоях сети (до 3 попыток, пауза 1→2→4 с)
- Понятные сообщения об ошибках без трейсбеков

## Быстрый старт

### Windows (PowerShell / cmd)

```powershell
# 1. Перейди в папку проекта
cd "c:\путь\к\папке\API_openWeather"

# 2. Создай виртуальное окружение и активируй его
python -m venv venv
venv\Scripts\activate

# 3. Установи зависимости
pip install -r requirements.txt

# 4. Укажи свой API-ключ в файле .env
# Открой .env и замени значение:
#   API_KEY=вставь_свой_ключ_сюда

# 5. Запусти приложение
python weather_app.py
```

### macOS / Linux (bash / zsh)

```bash
# 1. Перейди в папку проекта
cd /путь/к/папке/API_openWeather

# 2. Создай виртуальное окружение и активируй его
python3 -m venv venv

pip install -r requirements.txt

# 4. Укажи свой API-ключ в файле .env
# Открой .env и замени значение:
#   API_KEY=вставь_свой_ключ_сюда

# 5. Запусти приложение
python3 weather_app.py
```

## Получение API-ключа

1. Зарегистрируйся на [openweathermap.org](https://openweathermap.org/)
2. Перейди в **My Profile → API keys**
3. Скопируй ключ и вставь в `.env`:

```
API_KEY=твой_ключ_здесь
```

> Новые ключи активируются в течение 10–60 минут после регистрации.

## Использование

При запуске появится меню:

```
╔══════════════════════════════════╗
║     ПОГОДА — OpenWeather API     ║
╚══════════════════════════════════╝
  1 — Погода по названию города
  2 — Погода по координатам (lat, lon)
  0 — Выход
```

**Пример вывода:**

```
Погода в Москва: 12.4°C, пасмурно
```
